# Contributing to SCST1133

Registered SCST1133 students submit exercises using a fork and Pull Request.

## Allowed Scope

A student Pull Request should normally change only:

```text
submissions/section-XX/MATRIC-NUMBER-name/
```

Do not modify another student's work, repository instructions, templates or GitHub configuration files.

## Naming Conventions

- Branch: `exercise-XX-matric-number`
- Student folder: `MATRIC-NUMBER-name`
- Exercise folder: `exercise-XX`
- Pull Request: `[Section XX] Exercise XX - Matric Number - Name`

## Academic Integrity

Submitted work must represent the student's understanding and contribution. Acknowledge external materials and declare substantial AI assistance.

Never upload confidential data, personal documents, passwords, access tokens or private datasets.

## Review

A lecturer may approve the Pull Request, comment on files, request changes or close a submission that does not follow the required structure.
